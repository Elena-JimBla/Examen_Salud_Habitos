🧬 Proyecto: Análisis de Hábitos de Salud

Por Elena Jiménez Blasco

🩺 Descripción del proyecto

Vida en Datos es un análisis exploratorio realizado en Python que investiga la relación entre hábitos de vida y variables de salud en una población ficticia. A través de visualizaciones y estadísticas, se busca responder preguntas clave como:
¿Cómo influyen el sueño, la actividad física y el consumo de sustancias en la presión arterial, el IMC y la satisfacción con la vida?

📊 Metodología

El análisis parte de un dataset simulado llamado df_datos_salud_clean, que contiene variables como edad, género, IMC, presión arterial, nivel de actividad física, consumo de alcohol y tabaco, horas de sueño y satisfacción vital.
Etapas del análisis:
- Limpieza y depuración de datos (Python / Pandas)
- Análisis exploratorio de variables numéricas y categóricas
- Visualización con gráficos de dispersión, cajas, barras y mapas de calor
- Interpretación de patrones y relaciones entre variables
- Redacción de conclusiones y reflexiones sobre los resultados
  
📁 Estructura del repositorio

El repositorio se organiza en componentes que reflejan el flujo completo del trabajo:
- df_datos_salud_clean.csv – Dataset limpio y tratado
- datos_salud_habitos.csv – Dataset original
- Recu_Examen_M3_Final.ipynb – Notebook con análisis exploratorio
- Recu_Examen_M3_Visual_Final.ipynb – Notebook con visualizaciones
- README.md – Documento explicativo del proyecto
- 
🛠️ Herramientas utilizadas

- Python / Pandas / Matplotlib / Seaborn – Limpieza, análisis y visualización de datos
- Jupyter Notebook – Desarrollo del análisis paso a paso
- Excel – Apoyo en la revisión de datos
  
🧠 Conclusiones

Los datos muestran que existe una relación clara entre el nivel de actividad física y la presión arterial:
Las personas con mayor actividad tienden a tener presiones más saludables. También se observan patrones entre el sueño y la satisfacción con la vida, y entre el IMC y el riesgo de sobrepeso.
Este análisis permite reflexionar sobre cómo los hábitos cotidianos impactan directamente en la salud física y emocional. Aunque se trata de datos simulados, el ejercicio demuestra el poder del análisis de datos para entender y comunicar fenómenos complejos de forma accesible.
